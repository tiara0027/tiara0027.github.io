description of the tags

  • img: allows you to add an image to the web

  • src: used to provide the path to the image

  • alt: used to provide a description of the in case the image does not show

  • table: to create a table

  • caption: the description of the table

  • thead: helps to add a header to the table

  • tbody: helps to add a body to the table

  • tr: creates a table row

  • th: creates a heading cell

  • td: hepls to add the data in the table
